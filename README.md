# Functional Programming and Type Systems

*A seminar in five parts. Spring Quarter 1990.*

The slides are in [`fp.pdf`](fp.pdf), a Beamer deck of 47 pages. The original
tentative syllabus is in [`syllabus`](syllabus).

## Contents

1. **Reading Material and Schedule**
2. **Graph Reduction**
   - Combinators and program representation
   - The reduction rules
   - Lazy evaluation
   - Recursion and implementation
3. **Polymorphic Type Checking**
   - What polymorphism is
   - A language and its types
   - Inferring types
4. **Polymorphic Type Inference**
   - Polytypes
   - The inference system
5. **Continuation Passing Style**
   - Tail calls and continuations
   - The translation scheme

## Reading material

1. G. E. Révész, *Lambda-Calculus, Combinators, and Functional Programming*
2. D. A. Turner, *A New Implementation Technique for Applicative Languages*
3. L. Cardelli, *Basic Polymorphic Typechecking*
4. L. Cardelli and P. Wegner, *On Understanding Types, Data Abstraction, and Polymorphism*
5. P. Hudak, *Conception, Evolution, and Application of Functional Programming Languages* (survey)
